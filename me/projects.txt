# Current projects

## Dreamland v2
GitHub: https://github.com/TiinaTuuliaS/dreamland-v2
Live demo: https://verkkokauppa-projekti.onrender.com/

Dreamland v2 is a full-stack e-commerce application for a fictional jewellery brand. It includes customer registration and login, category browsing, product pages, a cart, discount coupons, Stripe Checkout, order confirmation emails, and a role-protected admin dashboard with product management and sales analytics.

Core technologies include React, Vite, Node.js, Express, MongoDB, Mongoose, JWT, bcrypt, Stripe, Resend, Cloudinary and Redis.

## AI Market Research Assistant
GitHub: https://github.com/TiinaTuuliaS/ai_research_assistant
Live demo: https://airesearchassistant-production-967c.up.railway.app/

This is a separate experimental application from the CV chatbot. Three AI agents produce source-backed competitor comparisons and market overviews. The work emphasises source traceability, structured data flow and evaluation of system reliability.

The app uses React, React Router, Framer Motion, FastAPI, CrewAI, OpenAI GPT-4.1-mini and GPT-4.1, Serper, Pydantic, SQLite, SQLAlchemy, Docker, Railway, uv, npm and automated tests. Pydantic models validate the structure of findings, source references and analysis; they do not guarantee that claims are true.

Two real example reports are publicly readable. Creating new research is limited to invited testers with an invite code, which keeps experimental API costs manageable. CrewAI is used in this project, not in the portfolio CV chatbot.

## Retkeilyapp
GitHub: https://github.com/TiinaTuuliaS/Retkeilyapp

Retkeilyapp is an active TypeScript project for exploring outdoor destinations and sharing practical observations. It includes account-based profiles, private journals, community sharing, friends, trip planning and offline observation saving.

Offline observations are stored first in IndexedDB and sent later when a connection returns. The app protects account ownership during retries and prevents duplicate submissions. Its backend work includes REST APIs, authentication, PostgreSQL and PostGIS.

## Portfolio
GitHub: https://github.com/TiinaTuuliaS/tiina-portfolio
CV page: /cv

This portfolio is itself a full-stack application and one of Tiina's projects. It is designed as an interactive alternative to a traditional CV: visitors can explore skills and selected work, use a Finnish or English AI CV chatbot, read or print a dedicated CV page, download a PDF CV, and send a message through a contact form.

It uses a React and Vite frontend, a Python and FastAPI backend, the OpenAI Responses API for the CV chatbot, and Resend for contact-form email. The design system, responsive interface, project case cards and chatbot experience were built specifically for this portfolio. The CV chatbot uses the OpenAI Responses API directly; it does not use CrewAI.
